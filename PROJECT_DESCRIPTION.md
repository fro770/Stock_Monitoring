# 📊 STOCK MONITORING — Система анализа и прогноза акций MOEX

Проект представляет собой систему для загрузки, хранения, анализа и прогнозирования
котировок акций Московской биржи (MOEX).

---

## ✨ Возможности

- 🌐 Загрузка котировок и списка ценных бумаг через официальный **MOEX ISS API**
- 🗄 Хранение истории цен в локальной базе данных **SQLite** (`data/stocks.db`)
- 🧠 Прогнозирование трендов на 1/7/14/30 дней:
  - технический / трендовый анализ (MA, RSI и др.);
  - ансамбль ML-моделей (Random Forest, XGBoost, LightGBM);
  - LLM-модель FinRL (Qwen + LoRA-адаптеры, FinBERT для тональности новостей);
- ⚡ Три режима анализа: быстрый, стандартный, глубокий (ансамбль)
- 📈 Автоматическая оптимизация весов моделей в ансамбле (композитный score, кэширование)
- 📝 Параллельная обработка тикеров (до 6 потоков)
- 📑 Отчёты в форматах **XLSX / CSV / JSON** с сортировкой по потенциалу роста
- 🖥 Интерактивное консольное меню + запуск через argparse
- 🪵 Подробное логирование всех этапов в `logs/`

---

| Требование | Версия |

## 🚀 Установка

### 0. Автоматическая настройка нового устройства (рекомендуется)

Для **самого первого запуска на новом ПК** в корне проекта есть скрипт
`setup_first_run.py`. Запустите его любым Python 3.8+:

```bash
Windows   : py setup_first_run.py        (или python setup_first_run.py)
Linux/macOS: python3 setup_first_run.py
```

Скрипт по шагам выполнит и проверит:
1. совместимость ОС (Windows 10/11, macOS 10.13+, Linux);
2. мощность ПК — ОЗУ, ядра CPU, свободное место на диске;
3. наличие Python целевой версии **3.11.9** (ищет все интерпретаторы в системе);
4. создание виртуального окружения `.venv` (если его нет) + обновление pip;
5. установку всех библиотек из `requirements.txt` (PyTorch — с CPU-индекса);
6. правильность архитектуры проекта (структура папок/файлов, импортность модулей,
   отсутствие устаревших файлов в корне);
7. доступ к MOEX ISS API.

При проблемах скрипт не просто предупреждает, а выдаёт инструкции «КАК ИСПРАВИТЬ»
с прямыми ссылками (например, инсталлятор Python 3.11.9 с python.org) и может
сам исправить часть проблем (перенос/удаление дублей, создание папок).

Флаги: `--check-only` (только диагностика), `--skip-install` (без установки
библиотек), `--yes` (автосогласие на автоматические исправления).

После успешной настройки переходите сразу к разделу «▶️ Запуск и работа».
Ниже — ручная установка (альтернатива скрипту).

### 1. Клонировать / скопировать проект

```bash
git clone <URL-репозитория> STOCK_MONITORING
cd STOCK_MONITORING
```

### 2. Создать виртуальное окружение (Python 3.11.9)

**Windows:**
```bat
py -3.11 -m venv venv
venv\Scripts\activate
```

**Linux / macOS:**
```bash
python3.11 -m venv venv
source venv/bin/activate
```

### 3. Установить зависимости

```bash
pip install --upgrade pip
pip install -r requirements.txt
```

> Для torch CPU-сборки можно явно:
> `pip install torch --index-url https://download.pytorch.org/whl/cpu`

### 4. Проверить установку

```bash
python test_connection.py
```

Скрипт протестирует: DataLoader, подключение к MOEX API, загрузку данных и работу анализатора.

## ▶️ Запуск и работа

### Быстрый старт (полная настройка «с нуля»)

```bash
# 1. Получить список всех акций MOEX → data/moex_all_shares.xlsx/.csv
python make_excel.py

# 2. Создать базу данных и загрузить тикеры
python init_db_and_load.py

# 3. Обновить историю котировок по всем тикерам
python update_data.py

# 4. Проверить, что всё работает
python test_connection.py

# 5. Запустить анализ
python main.py
```

### Основной сценарий — интерактивное меню

```bash
python main.py
```

Меню предлагает режимы:

```
1. 📈 Анализ акций (полный цикл)
2. 🔍 Проверка данных (валидация)
3. 📥 Только загрузка тикеров
4. 🚀 Быстрый анализ (топ-20)
5. ⚙️  Настройки
0. ❌ Выход
```

В режиме анализа последовательно запрашиваются:
- количество топ-акций (1–259 или «все»);
- тип акций (все / обыкновенные / привилегированные);
- режим: **1** — быстрый (только тренды), **2** — стандартный (ML + тренды), **3** — глубокий (ансамбль моделей);
- дни прогноза (например, `1,7,14,30`);
- минимальная уверенность (0–1).

По завершении в папке `reports/` создаются файлы:
`moex_analysis_<дата_время>.xlsx`, `.csv`, `.json`.

### Неинтерактивный запуск (CLI)

```bash
python analysis/main.py                       # то же самое, но с флагами
python analysis/main.py --mode 3 --top-n 100 --min-confidence 0.7
```

### Работа с данными

| Команда | Действие |
|---|---|
| `python make_excel.py` | Скачать полный список акций MOEX в Excel/CSV |
| `python init_db_and_load.py` | Инициализировать `data/stocks.db` и импортировать тикеры |
| `python update_data.py` | Догрузить/обновить свечи по всем тикерам из MOEX |
| `python test_connection.py` | Диагностика подключения и модулей |

### Просмотр результатов

- Отчёты: папка `reports/` (XLSX удобен для сортировки по потенциалу роста).
- Логи: папка `logs/` (`analysis.log`, `db_init.log`, `stock_data_fetcher.log` и др.).
- Данные: `sqlite3 data/stocks.db` или любой GUI-клиент (DB Browser for SQLite).

## ⚙️ Конфигурация

Основные настройки — в `analysis/core/config.py`:

| Параметр | Значение по умолчанию | Описание |
|---|---|---|
| `MOEX_BASE_URL` | `https://iss.moex.com/iss` | Адрес MOEX ISS API |
| `DEFAULT_PREDICTION_DAYS` | `[1, 7, 14, 30]` | Горизонты прогноза |
| `DEFAULT_HISTORY_DAYS` | `720` | Глубина истории (дней) |
| `MIN_HISTORY_DAYS` | `60` | Минимум данных для анализа |
| `MAX_WORKERS` | `6` | Параллельные потоки анализа |
| `MODES` | 1/2/3 | Режимы: быстрый / стандартный / глубокий |
| `TICKER_TIMEOUT` | `120 c` | Таймаут на один тикер |

Пути (`data/`, `reports/`, `logs/`, `models/`) задаются относительно корня проекта
и создаются автоматически.

## 🤖 Модели и веса

Каталоги `models/finbert-tone/` и `models/Qwen3-4B-FinRL-*/` содержат бинарные веса
и **не хранятся в git**. При их отсутствии система корректно работает в режимах
трендового и классического ML-анализа (режимы 1–2, частично 3). Для полноценной
LLM-аналитики скачайте веса моделей в соответствующие папки.

## 🛠 Устранение неполадок

| Симптом | Решение |
|---|---|
| Ошибка сети / таймаут MOEX | Проверьте доступ к `https://iss.moex.com/iss/statistics/engines/stock-markets/indexes`; при прокси задайте `HTTP_PROXY/HTTPS_PROXY` |
| `ModuleNotFoundError` | Убедитесь, что активировано venv: `venv\Scripts\activate` (Win) / `source venv/bin/activate` (Linux/macOS) |
| Пустые отчёты / мало данных | Выполните `python update_data.py` — история не загружена |
| Нет таблицы тикеров | Выполните `python make_excel.py && python init_db_and_load.py` |
| Медленный глубокий анализ | Уменьшите `--top-n` или используйте режим 1/2 |
| Логи пишутся в `logs/` | Файлы `logs/*.log` — первый источник диагностики |
